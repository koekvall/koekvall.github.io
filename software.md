R packages developed as part of my research.

[**sepcor**](https://github.com/koekvall/sepcor) --
Estimation and inference for separable correlation matrices.

[**reconf**](https://github.com/koekvall/reconf) --
Confidence intervals for variance components and covariance parameters in linear mixed models.

[**tpcr**](https://github.com/koekvall/tpcr) --
Targeted principal components regression.

[**fsnet**](https://github.com/koekvall/fsnet) --
Elastic net-regularized regression for interval-censored, categorical, and other finite-support responses.

[**mmrr**](https://github.com/koekvall/mmrr) --
Mixed-type multivariate response regression with covariance estimation.
